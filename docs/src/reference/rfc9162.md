# rfc9162

[Crate docs](../api/rfc9162/index.html). The module documentation includes a tested example that hashes `alpha`, `beta` and `gamma` and checks the inclusion proof for `beta`.

| Item | Role |
| --- | --- |
| [`leaf_hash`](../api/rfc9162/fn.leaf_hash.html) | `SHA-256(0x00 \|\| entry)` |
| [`node_hash`](../api/rfc9162/fn.node_hash.html) | `SHA-256(0x01 \|\| left \|\| right)` |
| [`root`](../api/rfc9162/fn.root.html) | Merkle root of a leaf slice, including the empty slice |
| [`inclusion_proof`](../api/rfc9162/fn.inclusion_proof.html) | sibling hashes, innermost first, or `None` when the index is outside the slice |
| [`verify_inclusion`](../api/rfc9162/fn.verify_inclusion.html) | folds a path back to a hexadecimal root |
| [`consistency_proof`](../api/rfc9162/fn.consistency_proof.html) | nodes that recompute an old root and a new root, or `None` when `old` is 0 or past the slice |
| [`verify_consistency`](../api/rfc9162/fn.verify_consistency.html) | checks that pair of roots |
| [`Head`](../api/rfc9162/struct.Head.html) | size and hexadecimal root; [`over`](../api/rfc9162/struct.Head.html#method.over) builds one; [`material`](../api/rfc9162/struct.Head.html#method.material) is the tab-separated signing input |
| [`hex`](../api/rfc9162/fn.hex.html) / [`from_hex`](../api/rfc9162/fn.from_hex.html) | lowercase hexadecimal for a 32-byte hash; `from_hex` accepts 64 digits in `0-9` and `a-f` |

The [tree how-to](../howto/rfc9162.md) runs these functions. The [Merkle tree](../topics/merkle-tree.md), [inclusion](../topics/inclusion.md) and [consistency](../topics/consistency.md) pages describe the results.
