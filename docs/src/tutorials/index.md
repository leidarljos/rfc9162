# Tutorials

Tutorials walk through one piece of work from an empty directory to a checked result.

- [Build a log and verify the proofs](build-a-log.md) stores three records, reads an inclusion proof back from the tiles, appends a fourth record, checks consistency, signs a checkpoint, and looks up a key in an indexed log.

[Getting started](../getting-started.md) is the shorter program that stops at the in-memory tree. The [how-to guides](../howto/index.md) are separate tasks for each crate.
